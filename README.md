# Sunny Skies Dashboard

Create a modern responsive Weather Dashboard using HTML, CSS, and JavaScript. Use asynchronous JavaScript with async/await and the Fetch API to fetch live weather data from the OpenWeatherMap API (or another free public weather API). Include a search box to search weather by city name. Display temperature, humidity, wind speed, weather condition, weather icon, and location. Add proper loading indicators, comprehensive error handling for invalid city names and network failures, and dynamically render the JSON response. Make the UI attractive, mobile-friendly, and ready for deployment on Vercel.
